06 / PASS OBSTACLE

Go forward. Steer around.

PASS MIC IDLE

“Forward 200 cm”

Needs the live camera and car, mode 4 and controls ON. Speaking a distance starts it straight away.

The car aims for the point straight ahead at your distance. Before every move it stops and checks one ultrasonic reading and a fresh camera image. Centre BLOCKED (ultrasonic at the limit or closer, or centre floor match under 70%) → turn one step toward the clearer side and check again. Once it is 20 cm past the obstacle along the line, it steers back toward the destination, rejoins the original line and ends facing the original direction.

ROVER / PRESENTATION CONSOLEMode 1: obstacle avoidance · Mode 2: line tracking · Mode 3: recovery · Mode 4: presentation
Setup & demo guide

A quick presentation run

  1. Start IP Webcam on Android. Connect phone and laptop to the same Wi-Fi or phone hotspot. Paste its HTTP address above.
  2. Upload SmartCar_Presentation.ino using Arduino IDE. Close Serial Monitor. Connect Arduino USB and select its COM port.
  3. Select mode 4 here or press remote button 4. Select Arm short steps only when the car is ready.
  4. Analyze only shows the camera hint and sensor readings. Analyze + one step also sends the permitted short action. The timeline separates sent, acknowledged and completed events.
  5. Use Speak command, or type a command. Stop / Esc cancels work. After Stop, clear it, select mode 4, and arm again.

The recorded backup is a real saved image with illustrative sensor readings. Its actions are labelled simulated. Live image analysis is a simple floor-colour experiment, not a trained reliable obstacle detector. Firmware IR arrows and modes 1–3 remain available and disarm dashboard control. Exact right-turn angle is not yet calibrated.
